THE LAST ARCHIVE — ENGLISH AUDIO AND MEDIA PRODUCTION

All character speech is synthesized English performance generated locally during development with Kokoro 82M v1.0. The static game contains finished MP3 files, not AI models, inference libraries, API keys or cloud-generation code.

MODEL AND VOICES
Kokoro 82M v1.0 and its official English voice tensors: Apache License 2.0.
Source: https://huggingface.co/hexgrad/Kokoro-82M
English stock voices used: af_heart, af_bella, af_nicole, bf_emma, bf_isabella, am_michael, am_fenrir, bm_george.
No custom real-person voice clone was used.
The upstream model acknowledges Koniwa (CC BY 3.0) and SIWIS (CC BY 4.0) training material. See the upstream model card for those acknowledgements.

ORIGINAL MUSIC AND EFFECTS
Music, ambient beds, ringing, notifications, transition sounds and the verification signal were mathematically synthesized specifically for this project. No third-party song, sample library, licensed subscription, or commercial sound-effect service was used. Production sources are kept with the development project. The overall project distribution licence remains the project owner's decision; no future asset royalty is introduced by these original sound files.

OTHER MEDIA
The surveillance extract is original authored fictional game media using a project-owned generated location photograph and an animated anonymous figure. It is not real surveillance footage. Document PDF and CSV assets are original exports of the game's English fictional records. Reference-board images supplied for inspiration were not copied into these materials.

PLAYBACK
Playback uses local static audio/video files and browser capabilities. There are no paid runtime services or recurring service requirements. Full offline availability is claimed only after the complete archive has been downloaded and verified in browser storage.

REVISED NARRATIVE EDITION
The active edition uses newly rendered recordings and transcripts. The earlier game, its original recordings and the lastarchive.v2 save remain separately preserved under editions/original/. The new edition does not interpret legacy deductions as its own. Each edition has its own offline-download scope.
