# Casework edition asset provenance

The apartment and supporting location images are original procedural Blender renders authored for this project. Their production scripts are in tools/rebuild. No stock textures, external image services or subscription assets are used.

The character portraits and original musical ambience are preserved project assets from the preceding playable edition. Refer to the root production provenance records for their original generation and licensing.

New dialogue is generated offline using Kokoro ONNX and its free voices. Only finished MP3 files and a small playback manifest are distributed. Kokoro model weights and the Python production environment are not included. Kokoro-82M is Apache-2.0; kokoro-onnx is MIT licensed. Production has no commercial TTS or runtime AI dependency.

The clock, lift and Morse clues are original locally synthesised sounds. Typography uses device/system fonts. Interface icons are original inline SVG paths.

The cinematic opening is a local FFmpeg edit of the canonical preserved-room renders with authored camera drift and colour grading. Its score, rain texture and latch are synthesized locally from deterministic waveforms/noise. It depicts no new event and supplies no exclusive evidence. The source editor is tools/rebuild/build_films.py. It is not stock film or a generated live-action scene.

The nine hotel camera samples are original Blender renders of the same hotel model and anonymous figure as the earlier retained still. The sampled video holds each source second without inventing intermediate action. Source code: tools/rebuild/render_surveillance.py. The camera has no audio. Reference images supplied by the owner are visual inspiration only; no watermarked stock image or third-party character/artwork from those references is shipped. Cork, pins, paper and connection strings in the investigation wall are original interface drawing/styles, with actual retained sources and player-authored theories.
