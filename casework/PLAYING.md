# THE LAST ARCHIVE — casework development edition

This is a separate development edition, not the published game or an approved release candidate. It contains an authored nine-chapter route. First-time pacing, difficulty and emotional impact still need independent playtesting. The 2–4 hour target is unmeasured.

## Play the self-contained review copy

1. Download and extract the `THE_LAST_ARCHIVE_CASEWORK_DEVELOPMENT` artifact from the latest successful casework verification run on Draft PR #4.
The review artifact is retained for seven days. Keep your downloaded copy and save backups.

2. Open `START_GAME.html` in your browser. It includes the finished images, recordings and game code. No installation, server or Python launcher is required.
3. Choose **Begin the investigation**. Follow the briefing and inspect the room before using the recovered phone.
4. Use **Casebook** for current lines of inquiry, source-linked observations, personal theories, notes and your working chronology.
5. Use **Settings / save** for sound controls and a downloadable save backup.

Keep the downloaded HTML in the same location while playing. Browser storage for local files differs between browsers; export a backup before moving the file, changing devices or downloading a later review build. Import that backup through Settings in another copy of this narrative edition. Earlier editions use separate saves and are not migrated or reset.

On iPhone or iPad, local HTML opened from Files may use a restricted preview instead of a full browser. Physical-device behaviour has not been certified. The normal hosted version is the intended mobile delivery format.

## Static web build

The accompanying `index.html`, `src`, `styles`, `assets`, manifest and service worker are a complete static web build with relative paths. They can be served under any directory on GitHub Pages. The first successful online installation caches this edition for offline use. No backend or runtime AI is needed.

The published main edition has not been replaced. Do not treat this development artifact as a production deployment.

## Controls and accessibility

Photographs support magnification, scrolling, a retained source mark and equivalent text descriptions. Recordings have transcripts, equivalent sound descriptions and replay controls. Optional hints remain available inside comparisons. Personal theories and chronology entries are never automatically treated as proof.

All production for this edition uses free local tools. Only finished media are included; no voice models or development environments are distributed. See `ASSET-LICENSES.md`.
